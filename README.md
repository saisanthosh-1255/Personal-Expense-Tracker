# Personal Expense Tracker 💰

A simple Python-based Personal Expense Tracker that helps users record and manage their daily expenses.

## Features

* Add expenses
* View all expenses
* Calculate total spending
* Search expenses by category
* Find highest expense
* Delete expenses
* Store data using JSON
* Command-line interface

## Technologies Used

* Python
* JSON
* File Handling
* Lists
* Dictionaries
* Functions
* Loops
* Conditional Statements

## How to Run

Clone the repository and open the project folder.

Run:

```bash
python main.py
```
